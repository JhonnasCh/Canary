Laboratorio de Simulación de Ciberataques

Comprueba la capacidad defensiva inmediata del Guardián 24/7. Al presionar cada botón, se enviará una sonda de prueba controlada contra el escudo para verificar que sea neutralizada y registrada en el SOC en vivo.

Inyección SQL (SQLi)

Intenta alterar una consulta de base de datos para saltarse la autenticación.

' OR '1'='1'--

Inyección Script XSS

Intenta inyectar código JavaScript malicioso para robar cookies de sesión.

<script>document.location=...</script>

Salto de Directorio (LFI)

Intenta escapar del directorio web para leer archivos del sistema operativo.

../../../../etc/passwd

Comandos de Shell (RCE)

Intenta concatenar operadores de shell para ejecutar instrucciones en el servidor.

127.0.0.1; cat /etc/shadow

Escáner Hostil

Simula el sondeo masivo ejecutado por herramientas automáticas como sqlmap.

User-Agent: sqlmap/1.7.2#stable

Conectar el Guardián 24/7 a tu Web

Protege el sitio web o API de tus clientes en tiempo real integrando este middleware ultraligero:

Paso 1: Copia el agente a tu servidor

El archivo sentinel-agent.js ya se encuentra en src/guardian-agent/ listo para ser importado en tus proyectos Express, Node.js o Next.js.

Paso 2: Activa el escudo en 2 líneas de código

const { canaryGuardian } = require('./sentinel-agent'); // Conecta el escudo 24/7 a tu aplicación Express app.use(canaryGuardian({ hubUrl: window.location.origin, blockMode: true // Bloquea con HTTP 403 Forbidden }));

Paso 3: ¡Listo! Tu web está protegida 24/7

Cualquier intento de ataque será neutralizado en el acto y los registros aparecerán en el Centro Guardián en vivo.
